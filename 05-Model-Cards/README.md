# Model Cards

AI governance model cards: single-document governance summaries for each assessed
platform. A model card consolidates the platform assessment, risk assessment, and
control library into one artifact and states an approval recommendation — the
document leadership, auditors, and future governance teams read first to understand
how a platform is governed, monitored, and approved for use.

Each card covers the platform's purpose and ownership, intended and prohibited use,
data considerations, key risks (cross-referenced to the Risk Assessment by risk ID),
required controls (referenced from the Control Library), human oversight and
monitoring requirements, and a documented approval decision with justification.
