# Control Library

Governance controls required before a platform is approved for use. Each control traces to a risk identified in `02-Risk-Assessments`, names an owner, defines how and when it operates, and specifies the evidence it produces. Controls combine traditional IT controls with AI-specific controls and are mapped to NIST SP 800-53 Rev. 5 where applicable.
